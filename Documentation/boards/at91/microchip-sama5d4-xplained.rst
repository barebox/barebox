Atmel SAMA5D4 XPLAINED ULTRA Evaluation Kit
===========================================

Support for this board is currently marked as broken:
``CONFIG_MACH_SAMA5D4_XPLAINED`` depends on ``CONFIG_BROKEN`` and the former
``sama5d4_xplained_defconfig`` has been removed. To build barebox for this
board, enable ``CONFIG_BROKEN`` and select the board manually in the
configuration.
