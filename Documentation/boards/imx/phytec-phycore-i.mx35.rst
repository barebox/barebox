Phytec phyCORE-i.MX35
=====================

Support for this board was removed in barebox v2023.04.0. The last release
containing it was v2023.03.0, where building the bootloader image for this
target was covered by the ``phytec-phycore-imx35_defconfig``.

The resulting ``barebox.bin`` file could be used for booting in
``internal mode`` from NAND or NOR memory.
